¿Dónde nació NamuVT Studios?

NamuVT Studios nació en Argentina, Buenos Aires.

¿Cuáles son los 21 programas del ecosistema NVTS?

El catálogo oficial está formado por NVTS-PhotoMania, NVTS-MixerDAW, NVTS-PremiereSurprise, NVTS-MultiEncoder, NVTS-FusionFX, NVTS-Vectorize, NVTS-Docs, NVTS-Sheets, NVTS-Deck, NVTS-Pixelize, NVTS-Designer, NVTS-Oven, NVTS-FigGUI, NVTS-GameEngine, NVTS-SimulationEngine, NVTS-Symphony, NVTS-CAD, NVTS-Works, NVTS-PDF, NVTS-Light y NVTS-Codex. NVTS-Launcher es la aplicación complementaria de escritorio y Procedural Field Maker se conserva como herramienta independiente.

El ecosistema abarca edición y revelado fotográfico, ilustración, audio, video, codificación multimedia, efectos visuales, diseño vectorial y editorial, documentos PDF, productividad, pixel art, creación 3D, diseño de interfaces, desarrollo de software, videojuegos, animación 2D, simulaciones para experimentación y videojuegos, CAD y gestión del estudio.

¿Qué programas utilizamos y para qué funciones?

Estas son algunas de las herramientas que forman parte de nuestros procesos de producción y desarrollo:

  • AFTER EFFECTS para Postproducción de mis PROYECTOS , tanto personales de YouTube (Animaciones, VFX, Motion Graphics, etc.), como profesionales de NamuVT Studios (Cutscenes, VFX, Motion Graphics, etc.).
  • ANDROID STUDIO para exportar Videojuegos a Android.
  • ARDUINO para PROYECTOS de ROBÓTICA y ELECTRÓNICA , tanto personales de YouTube , como profesionales de NamuVT Studios (Juegos Electrónicos, etc.).
  • ASEPRITE para hacer PIXEL ART , tanto para PROYECTOS personales de YouTube (Cosplays de mi Avatar, Curis, etc.), como profesionales de NamuVT Studios (Spritesheets, Portadas, UV Mapping, etc.).
  • AUDITION para Producción y Postproducción de mis PROYECTOS , tanto personales de YouTube (Videos, Canciones, etc.), como profesionales de NamuVT Studios (Música para Videojuegos, Trailers de Videojuegos, etc.).
  • BLENDER para Modelado 3D, Animación 3D, Texturizado, UV Mapping y Rigging 3D, tanto PROYECTOS personales de YouTube (VTubers, Modelos 3D, etc.), como profesionales de NamuVT Studios (Escenas de Videojuegos, Modelos 3D, etc.).
  • CLAUDE para la Preproducción y Producción de mis PROYECTOS , tanto personales de YouTube (Videos, Guiones, etc.), como profesionales de NamuVT Studios (GDD, TDD, QA, Tests de Código, etc.).
  • FIGMA para diseñar el flujo de los menús, pantallas de carga, inventarios y pantallas de juego (HUD), permitiendo crear prototipos interactivos antes de programarlos.
  • FLAMESHOT para hacer capturas de pantalla en el PC.
  • GB STUDIO para crear Videojuegos de Game Boy, tanto personales de YouTube , como profesionales de NamuVT Studios (Plataformas, Aventuras, etc.).
  • GITHUB DESKTOP para el control de versiones de mis trabajos en GitHub, tanto Videojuegos (Plataformas, Aventuras, etc.), como Softwares (Simulación, Diseño/Animación 2D, Diseño/Animación 3D, Motor de Videojuegos, etc.).
  • ILLUSTRATOR para Ilustraciones Vectoriales de mis PROYECTOS , tanto personales de YouTube (Fondos, Illustraciones, etc.), como profesionales de NamuVT Studios (Logos, Sprites, etc.).
  • JIRA para gestionar todos mis PROYECTOS de Videojuegos y Softwares, tanto si uso Metodología SCRUM como si uso KANBAN .
  • KRITA para hacer Obras Literarias e Ilustraciones 2D, tanto para PROYECTOS personales de YouTube (Ilustraciones para Miniaturas, Cosplays de mi Avatar, Curis, Novelas, Mangas, Manhwas, etc.), como profesionales de NamuVT Studios (Spritesheets, Concept Art, Character Design, Portadas, Novelas de mis IP, Mangas de mis IP, Manhwas de mis IP, etc.).
  • MEDIA ENCODER para exportar mis PROYECTOS de Premiere Pro, tanto personales de YouTube (Videos, etc.), como profesionales de NamuVT Studios (Trailers de Videojuegos, etc.).
  • MELD STUDIO para grabar el Gameplay de mis Videojuegos.
  • NVTS-WORKS para la gestión interna de NamuVT Studios: organización de proyectos, tableros Kanban, tareas, incidencias, responsables, prioridades, sprints, calendarios y seguimiento del trabajo.
  • PHOTOSHOP para hacer las Miniaturas, y editar los Assets de mis Videojuegos (Sprites, Fondos, Portadas, etc.), tanto personales de YouTube , como profesionales de NamuVT Studios .
  • PREMIERE PRO para Postproducción de mis PROYECTOS , tanto personales de YouTube (Videos, Canciones, etc.), como profesionales de NamuVT Studios (Videos, Trailers de Videojuegos, etc.).
  • TRELLO para gestionar todo mi trabajo usando Metodología KANBAN .
  • VISUAL STUDIO CODE para Diseño y Desarrollo Web.
  • VISUAL STUDIO para mis PROYECTOS de Softwares y Videojuegos en UNITY .
