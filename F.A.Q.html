¿QUE PROGRAMAS UTILIZAN Y PARA QUE FUNCIONES?

Utilizamos varios programas, tanto para nuestros videos como para nuestros otros trabajos:

  • AFTER EFFECTS para la Postproducción de la parte Artistica de nuestros Videojuegos y Videos (Cutscenes, VFX, Motion Graphics, etc.).

  • ANDROID STUDIO para exportar Videojuegos a Android y iOS, y para el desarrollo de aplicaciones móviles.

  • ASEPRITE para hacer Pixel Art para nuestros Videojuegos (Spritesheets, Portadas, etc.) y hacer Ilustraciones para Miniaturas (Cosplays de nuestro Avatar, Curis, etc.).

  • AUDITION para grabar y editar el Audio de nuestros Proyectos (Videos, Trailers de Videojuegos, etc.).

  • BLENDER para Modelado y Animación 3D (VTubers, Escenas de Videojuegos, Modelos 3D, etc.), Texturizado, UV Mapping y Rigging 3D.

  • CLAUDE para crear aplicaciones, juegos, guiones y contenido generado por IA.

  • CLIP STUDIO PAINT para hacer Obras Literarias (Novelas, Mangas, Manhwas, etc.).

  • EMOTELAB para hacer Emotes y Alertas.

  • FLAMESHOT para hacer capturas de pantalla en el PC.

  • GITHUB DESKTOP para el control de versiones de nuestros trabajos en GitHub.

  • GODOT para crear Videojuegos 2D, tanto para proyectos personales para YouTube como profesionales de NamuVT Studios (Plataformas, Aventuras, etc.).

  • ILLUSTRATOR para Ilustraciones Vectoriales, tanto de Videojuegos como de otros proyectos (Logos, Sprites, etc.).

  • KRITA para Ilustraciones 2D de videojuegos (Concept Art, Character Design, Modelos VTubers, etc.), y hacer Ilustraciones para Miniaturas (Cosplays de nuestros Avatares, Curis, etc.).

  • MEDIA ENCODER para exportar nuestros Proyectos (Videos, Trailers de Videojuegos, etc.).

  • OBS STUDIO para hacer nuestros videos y directos, y para Grabar el Gameplay de nuestros Videojuegos.

  • PHOTOSHOP para hacer las Miniaturas, y editar los assets de nuestros videojuegos (Sprites, Fondos, Portadas, etc.).

  • PREMIERE PRO para editar nuestros Proyectos (Videos, Trailers de Videojuegos, etc.).

  • UNITY para crear Videojuegos 3D, tanto para proyectos personales para YouTube como profesionales de NamuVT Studios (Plataformas, Aventuras, etc.) o crear Aplicaciones para NamuVT Studios (Apps para VTubers).

  • VEADOTUBE MINI para usar nuestros avatares PNG en nuestros videos y directos.

  • VISUAL STUDIO CODE para programar nuestros proyectos de software y videojuegos.

  • VOICE WAVE para modificar nuestra voz para cuando usamos un OC propio en nuestros videos.

  • Estoy aprendiendo a usar DEFOLD, FL STUDIO, FREE TEXTURE PACKER, GB STUDIO, LIVE2D, REAPER, SUBSTANCE 3D DESIGNER/PAINTER, TOON BOOM HARMONY, VSEE FACE, VTUBE STUDIO, y XD.
