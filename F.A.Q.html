¿QUE PROGRAMAS UTILIZAN Y PARA QUE FUNCIONES?

Utilizo varios programas, tanto para mis videos como para mis otros trabajos:

  • AFTER EFFECTS para la Postproducción de la parte Artistica de mis Videojuegos (Cutscenes, VFX, Motion Graphics, etc.) y Videos (Cutscenes, VFX, Motion Graphics, etc.).

  • ANDROID STUDIO para exportar Videojuegos a Android.

  • ASEPRITE para hacer Pixel Art para mis Videojuegos (Spritesheets, Portadas, etc.) y hacer Ilustraciones para Miniaturas (Cosplays de mi Avatar, Ilustraciones para Miniaturas, etc.).

  • AUDITION para grabar y editar el Audio de mis Proyectos (Videos, Trailers de Videojuegos, etc.).

  • BLENDER para Modelado y Animación 3D (VTubers, Escenas de Videojuegos, Modelos 3D, etc.), Texturizado, UV Mapping y Rigging.

  • CLIP STUDIO PAINT para hacer Obras Literarias (Novelas, Mangas, Manhwas, etc.).

  • EMOTELAB para hacer Emotes y Alertas.

  • FLAMESHOT para hacer capturas de pantalla en el PC.

  • GITHUB DESKTOP para el control de versiones de mis trabajos en GitHub.

  • GODOT para crear Videojuegos 2D.

  • ILLUSTRATOR para Ilustraciones Vectoriales, tanto de Videojuegos como de otros proyectos (Logos, Sprites, etc.).

  • KRITA para Ilustraciones 2D de videojuegos (Concept Art, Character Design, Modelos VTubers, etc.), Animación 2D (CutScenes, etc.) y hacer Ilustraciones para Miniaturas (Cosplays de mi Avatar, Ilustraciones para Miniaturas, etc.).

  • MEDIA ENCODER para exportar mis Proyectos (Videos, Trailers de Videojuegos, etc.).

  • OBS STUDIO para hacer mis videos y directos, y para Grabar el Gameplay de mis Videojuegos.

  • PHOTOSHOP para hacer las Miniaturas, y editar los assets de mis videojuegos (Sprites, Fondos, Portadas, etc.).

  • PREMIERE PRO para editar mis Proyectos (Videos, Trailers de Videojuegos, etc.).

  • UNITY para crear videojuegos si no quiero usar Godot o crear Aplicaciones de VTubing.

  • VEADOTUBE MINI para usar mis avatares PNG en mis videos y directos.

  • VISUAL STUDIO CODE para programar mis proyectos de software y videojuegos.

  • VOICE WAVE para modificar mi voz para cuando uso un OC propio en mis videos.

  • Estoy aprendiendo a usar Blackbox, FL Studio, Free Texture Packer, GB Studio, Live2D, Reaper, Substance 3D Designer/Painter, Toon Boom Harmony, VSee Face, VTube Studio, y XD.
