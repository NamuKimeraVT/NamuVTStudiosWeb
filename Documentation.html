NVTS-PhotoMania

Photo editing, raster illustration, and digital compositing.

Version 1.0 documented
Version 1.0

Initial public documentation for NVTS-PhotoMania 1.0. This version page records the application scope and the main workflows covered by the first release.

Getting started

Understand the purpose of PhotoMania, the supported image-editing workflow, and the basic steps for starting or opening an image document.

Workspace and canvas

Learn the role of the editing workspace, the document canvas, navigation, zoom, and the visual work area.

Painting, selections, and retouching

Reference the core image-creation and editing categories: painting tools, selections, and pixel-level retouching.

Layers and masks

Understand layer-based editing and the non-destructive concepts used to isolate and control image changes.

Adjustments, filters, and styles

Explore the purpose of image adjustments, filters, and non-destructive visual styling in the editing workflow.

Guides, symmetry, and print preparation

Review the guide and symmetry workflows, along with resources for preparing comic pages and images for print.

Import and export

Use the file workflow to bring image assets into a document and prepare the finished image for output.

This is the version 1.0 public documentation outline. Detailed command-by-command instructions and format-specific behavior should be expanded against the final 1.0 application build.

When a later release is published, it will receive a separate version section (for example, 1.5). The 1.0 documentation will remain available and unchanged.
